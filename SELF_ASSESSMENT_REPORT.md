CI stayed red on that commit, but the test suite was not right the first time, so we take a point off criterion 6.

- `AGENTS.md` is short per section, but the Never list and the Permissions table are long; a stricter reading of "short" could cost a point.
- Some AI-LOG entries record "Changed: nothing" (package manager, A4), which is true but thin.
